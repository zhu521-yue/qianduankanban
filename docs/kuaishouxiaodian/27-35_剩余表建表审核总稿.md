## 0. 统一业务规则

第27—35张表统一遵守以下已经确认的规则：

1. 客户相关表只使用`渠道 = '分销'`的数据。
2. 有效销售状态为`交易成功`、`已发货`、`已收货`。
3. 客户ID优先级：CPS达人ID → 团长ID → 快赚客ID；三者均为空则作废。
4. 商品编码只使用去除首尾空格后的`SKU编码`；SKU为空则不进入客户商品表，不使用其他字段替代。
5. 交易金额使用`实付款`，保存毛销售额，不直接扣减退款。
6. 商品数量使用`成交数量`。
7. 拿货次数等于对应周期内该客户在`customer_daily_sales`中出现的日记录数，不等于原始订单行数。
8. 自然周为星期一至星期日；自然月为每月1日至月末。
9. 业务季度：2—4月、5—7月、8—10月、11月—次年1月。
10. 业务半年：2—7月、8月—次年1月。
11. 所有金额字段均为`NUMERIC(18,2)`；健康度得分为`NUMERIC(5,2)`。
12. 第27—34张已在同一个总事务内完成；第35张经再次确认后在独立事务内完成。两个事务均执行建表、写入、逐键重算和强制校验，只有全部通过才提交。

### 27.6 正式执行的建表与生成SQL

```sql
CREATE TABLE kuaishouxiaodian.customer_weekly_sales (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    period_start DATE NOT NULL,
    period_end DATE NOT NULL,
    customer_id TEXT NOT NULL,
    weekly_transaction_amount NUMERIC(18,2) NOT NULL DEFAULT 0,
    weekly_purchase_count BIGINT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CHECK (EXTRACT(ISODOW FROM period_start) = 1 AND period_end = period_start + 6),
    UNIQUE (customer_id, period_start, period_end)
);

INSERT INTO kuaishouxiaodian.customer_weekly_sales (
    period_start, period_end, customer_id,
    weekly_transaction_amount, weekly_purchase_count
)
SELECT
    DATE_TRUNC('week', transaction_date)::DATE,
    DATE_TRUNC('week', transaction_date)::DATE + 6,
    customer_id,
    SUM(transaction_amount)::NUMERIC(18,2),
    COUNT(*)::BIGINT
FROM kuaishouxiaodian.customer_daily_sales
GROUP BY 1, 2, 3
ORDER BY customer_id, 1;
```

### 29.6 正式执行的建表与生成SQL

```sql
CREATE TABLE kuaishouxiaodian.customer_quarterly_sales (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    period_start DATE NOT NULL,
    period_end DATE NOT NULL,
    customer_id TEXT NOT NULL,
    quarterly_transaction_amount NUMERIC(18,2) NOT NULL DEFAULT 0,
    quarterly_purchase_count BIGINT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CHECK (
        EXTRACT(MONTH FROM period_start) IN (2,5,8,11)
        AND period_end = (period_start + INTERVAL '3 months' - INTERVAL '1 day')::DATE
    ),
    UNIQUE (customer_id, period_start, period_end)
);

INSERT INTO kuaishouxiaodian.customer_quarterly_sales (
    period_start, period_end, customer_id,
    quarterly_transaction_amount, quarterly_purchase_count
)
WITH base AS (
    SELECT
        (DATE_TRUNC('quarter', transaction_date - INTERVAL '1 month') + INTERVAL '1 month')::DATE AS period_start,
        customer_id, transaction_amount
    FROM kuaishouxiaodian.customer_daily_sales
)
SELECT period_start,
       (period_start + INTERVAL '3 months' - INTERVAL '1 day')::DATE,
       customer_id,
       SUM(transaction_amount)::NUMERIC(18,2),
       COUNT(*)::BIGINT
FROM base
GROUP BY 1, 2, 3
ORDER BY customer_id, 1;
```

```sql
CREATE TABLE kuaishouxiaodian.customer_daily_product_sales (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    transaction_date DATE NOT NULL,
    customer_id TEXT NOT NULL,
    product_code TEXT NOT NULL,
    transaction_amount NUMERIC(18,2) NOT NULL DEFAULT 0,

WITH resolved AS (
    SELECT
        ("订单创建时间" AT TIME ZONE 'Asia/Shanghai')::DATE AS transaction_date,
        CASE
            WHEN NULLIF(BTRIM("CPS达人ID"::TEXT), '') IS NOT NULL THEN BTRIM("CPS达人ID"::TEXT)
            WHEN NULLIF(BTRIM("团长ID"::TEXT), '') IS NOT NULL THEN BTRIM("团长ID"::TEXT)
            WHEN NULLIF(BTRIM("快赚客ID"::TEXT), '') IS NOT NULL THEN BTRIM("快赚客ID"::TEXT)
            ELSE NULL
        END AS customer_id,
        NULLIF(BTRIM("SKU编码"::TEXT), '') AS product_code,
        "实付款" AS transaction_amount,
        "成交数量" AS product_quantity
    FROM kuaishouxiaodian.raw_data
    WHERE "订单状态" IN ('交易成功', '已发货', '已收货')
      AND BTRIM("渠道"::TEXT) = '分销'
)
INSERT INTO kuaishouxiaodian.customer_daily_product_sales (
    transaction_date, customer_id, product_code,
    transaction_amount, product_quantity
)
SELECT transaction_date, customer_id, product_code,
       SUM(transaction_amount)::NUMERIC(18,2),
       SUM(product_quantity)::BIGINT
FROM resolved
WHERE customer_id IS NOT NULL AND product_code IS NOT NULL
GROUP BY 1, 2, 3
ORDER BY customer_id, transaction_date, product_code;
```

```sql
    SELECT
        (
            DATE_TRUNC('year', transaction_date - INTERVAL '1 month')
            + CASE
                WHEN EXTRACT(MONTH FROM transaction_date - INTERVAL '1 month') <= 6
                    THEN INTERVAL '1 month'
                ELSE INTERVAL '7 months'

        customer_id, product_code, transaction_amount, product_quantity

SELECT period_start,
       (period_start + INTERVAL '6 months' - INTERVAL '1 day')::DATE,
       customer_id, product_code,

FROM base
GROUP BY 1, 2, 3, 4
```

### 35.3 健康度计算准则

拿货次数子得分：

| 半年拿货次数 | 子得分 |
|---:|---:|
| 大于等于4次 | 100 |
| 3次 | 80 |
| 1—2次 | 60 |
| 0次 | 20 |

拿货金额子得分：

| 半年拿货金额 | 子得分 |
|---:|---:|
| 大于等于550,000 | 100 |
| 400,000—不足550,000 | 80 |
| 200,000—不足400,000 | 70 |
| 100,000—不足200,000 | 60 |
| 50,000—不足100,000 | 40 |
| 10,000—不足50,000 | 20 |
| 不足10,000 | 10 |

```text
健康度得分 = 拿货次数子得分 × 40% + 拿货金额子得分 × 60%
```

得分保留2位小数，状态划分如下：

| 健康度得分 | 健康状态 |
|---:|---|
| 大于等于90 | 高活跃 |
| 80—不足90 | 活跃 |
| 70—不足80 | 稳定 |
| 50—不足70 | 观察 |
| 40—不足50 | 风险 |
| 20—不足40 | 流失预警 |
| 不足20 | 流失 |

### 35.4 计算流程

```text
读取customer_half_year_sales
→ 逐客户、逐业务半年读取拿货次数和拿货金额
→ 分别计算次数子得分和金额子得分
→ 按40%与60%加权并保留2位小数
→ 根据总分映射健康状态
→ risk_reason和follow_up_action暂存NULL
```

### 35.7 正式执行的建表与生成SQL

```sql
CREATE TABLE kuaishouxiaodian.customer_health_detail (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    period_start DATE NOT NULL,
    period_end DATE NOT NULL,
    customer_id TEXT NOT NULL,
    half_year_purchase_count BIGINT NOT NULL DEFAULT 0,
    half_year_purchase_amount NUMERIC(18,2) NOT NULL DEFAULT 0,
    customer_health_score NUMERIC(5,2) NOT NULL,
    customer_health_status TEXT NOT NULL,
    risk_reason TEXT,
    follow_up_action TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CHECK (
        EXTRACT(MONTH FROM period_start) IN (2,8)
        AND period_end = (period_start + INTERVAL '6 months' - INTERVAL '1 day')::DATE
    ),
    CHECK (customer_health_score BETWEEN 0 AND 100),
    UNIQUE (customer_id, period_start, period_end)
);

INSERT INTO kuaishouxiaodian.customer_health_detail (
    period_start, period_end, customer_id,
    half_year_purchase_count, half_year_purchase_amount,
    customer_health_score, customer_health_status,
    risk_reason, follow_up_action
)
WITH subscores AS (
    SELECT
        period_start, period_end, customer_id,
        half_year_purchase_count,
        half_year_transaction_amount AS half_year_purchase_amount,
        CASE
            WHEN half_year_purchase_count >= 4 THEN 100
            WHEN half_year_purchase_count = 3 THEN 80
            WHEN half_year_purchase_count IN (1,2) THEN 60
            ELSE 20
        END::NUMERIC AS count_score,
        CASE
            WHEN half_year_transaction_amount >= 550000 THEN 100
            WHEN half_year_transaction_amount >= 400000 THEN 80
            WHEN half_year_transaction_amount >= 200000 THEN 70
            WHEN half_year_transaction_amount >= 100000 THEN 60
            WHEN half_year_transaction_amount >= 50000 THEN 40
            WHEN half_year_transaction_amount >= 10000 THEN 20
            ELSE 10
        END::NUMERIC AS amount_score
    FROM kuaishouxiaodian.customer_half_year_sales
), scored AS (
    SELECT *, ROUND(count_score * 0.4 + amount_score * 0.6, 2) AS health_score
    FROM subscores
)
SELECT
    period_start, period_end, customer_id,
    half_year_purchase_count, half_year_purchase_amount,
    health_score,
    CASE
        WHEN health_score >= 90 THEN '高活跃'
        WHEN health_score >= 80 THEN '活跃'
        WHEN health_score >= 70 THEN '稳定'
        WHEN health_score >= 50 THEN '观察'
        WHEN health_score >= 40 THEN '风险'
        WHEN health_score >= 20 THEN '流失预警'
        ELSE '流失'
    END,
    NULL, NULL
FROM scored
ORDER BY customer_id, period_start;
```
